# PF-Lab02 — Programming Fundamentals Lab

C programming lab tasks completed as part of the **Programming Fundamentals** course, BS Artificial Intelligence, FAST-NUCES Peshawar.

Roll number: **p260051**

## 📂 Structure

All tasks live inside the `p260051 lab task 1/` folder. Each task has a `.c` source file and its compiled `.exe`.

## 📋 Task Index

| File | Description |
|---|---|
| `p260051_task2.c` | Prints a FAST-NUCES student profile card — batch year, section, test score, and semester fee — using `int`, `char`, `float`, and `double` variables with formatted `printf` output. |
| `p260051_task3.c` | Demonstrates C escape sequences: printing a double quote, a literal backslash, a newline break, a horizontal tab, and a percent sign. |
| `p260051_task4.c` | Declares a variable of each basic data type (`char`, `int`, `float`, `double`) and prints its value alongside its size in memory using `sizeof()`. |
| `p260051_task5.c` | Converts a given Celsius temperature to both Fahrenheit and Kelvin and prints all three values. |
| `p260051_task6.c` | Circle geometry calculator — given a radius, computes and prints the diameter, circumference, and area. |
| `p260051_task7.c` | Kinematics calculator — given initial velocity, acceleration, and time, computes final velocity and distance traveled using the equations of motion. |
| `p260051_task8.c` | Bank loan interest summary — given principal, annual interest rate, and loan duration, computes simple interest, total payable amount, and the monthly installment. |
| `p260051_task9.c` | Monthly salary slip generator — given a basic salary, computes house rent allowance (20%), medical allowance (10%), gross salary, tax deduction (5%), and net payable salary. |
| `p260051_task10.c` | Semester academic report — given marks and credit hours for three courses, computes the total credit hours and the weighted average percentage. |
| `p260051_task11.c` | FAST Cafeteria receipt generator — given item quantities and unit prices (tea, samosa, chicken roll), computes each subtotal, the overall subtotal, 16% GST, and the grand total. |

*(Task 1 is not included in this set — index starts at Task 2.)*

## 🧠 Concepts covered

- Variables and data types (`int`, `float`, `double`, `char`)
- `sizeof()` and memory sizes of data types
- Escape sequences
- Arithmetic operators and formulas
- Formatted output with `printf` (`\t`, `%d`, `%c`, `%.2f`, etc.)
- Real-world calculation problems: finance (interest, salary, tax), physics (kinematics), geometry, and billing/receipts

## 🛠️ How to compile & run

Each task is a standalone C file. Using GCC:

```bash
gcc p260051_taskN.c -o p260051_taskN
./p260051_taskN
```

(On Windows, this produces the `.exe` files already included in the folder.)
